§ 00

How to use this document

READ FIRST

Work through the sections in any order. Where the site already contains a placeholder, it is shown in an orange-marked box so you can either confirm it or correct it — you do not have to write everything from scratch.

Three ways to return it.
1. Write directly into this PDF and email it back.
2. Print it, complete by hand, and scan.
3. Use it as a checklist and send the content in a document or shared folder, keeping the same section numbers.
Priority markers.
Essential  Blocks launch — the page cannot go live without it.

Important  Should be real at launch; a sensible interim version is possible.

Optional  Can be added after launch without rework.
Photography specification.
All imagery on the site is currently licensed stock. To use your own:

· Landscape shots: 2000 px wide minimum, JPG
· Team portraits: 900 × 1200 px minimum, vertical, plain or blurred background
· Logos: SVG preferred, otherwise PNG with transparency
· Send originals, not screenshots or images pulled from social media
· Confirm you hold the right to publish each photograph
A note on honesty.
Statistics, project figures and testimonials on the site are currently invented for demonstration. Please replace them with figures you can evidence. Anything you are unsure about, mark “cannot confirm” and we will remove that element rather than publish a number that cannot be defended.
